# MAX7219 framebuffer and mapping

Logical row and column arguments range from 1 to 8. Out-of-range coordinates
and NULL patterns are ignored. The framebuffer contains one byte per physical row.

Orientation and mirror constants are in include/drivers/max7219/max7219_config.h.
With the current default mapping, logical (1,1) selects register 1, bit 0;
logical (2,3) selects register 3, bit 1. The orientation labels follow this module's
physical arrangement. Verify the corner demo when changing the matrix hardware.

max7219_set_pixel updates one physical row. max7219_draw_pattern maps the entire
8×8 source before sending eight register writes. It does not expose intermediate
per-pixel updates. Initialization configures decode mode, scan limit, intensity
and normal display operation, then clears all rows.

Host tests cover the default mapping and transfer count. Other orientation/mirror
configurations and electrical operation need their own validation.
